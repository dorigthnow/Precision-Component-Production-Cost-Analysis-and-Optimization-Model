# 精密零部件产能-成本-利润数据分析建模



## 项目简介



该项目旨在构建特种加工场景下的产能-成本预测模型，并利用根据精密特种加工和成本会计的业务逻辑生成的虚拟数据对其进行训练，通过寻优求解以获得产能、收益、成本最优平衡，并分析各影响因素的权重配比。



项目采用了 DFD 数据流图、UML 完成项目系统结构化设计，技术栈包括：R、MySQL、MATLAB，后续可能会添加 PowerBI、Airflow。



该项目是为本科统计学生的学业实践设计原型项目。



## 技术栈



- 数据分析与算法实现：R

- 数据库的实现与部署：MySQL

- 可视化：MATLAB、R
